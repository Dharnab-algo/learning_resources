# 📚 My Learning Resources

Ye repo mera personal collection hai un sab links/resources ka jo maine kabhi bhi seekhne ke liye use kiye ya save kiye — taaki dobara search na karna pade.

## 📂 Structure

| Folder | Kya hai isme |
|---|---|
| [web-development](./web-development) | HTML, CSS, JS, React, Node etc. |
| [python](./python) | Python courses, docs, projects |
| [dsa](./dsa) | Data Structures & Algorithms |
| [ml-ai](./ml-ai) | Machine Learning / AI resources |
| [other](./other) | Jo kahin fit na ho |

## ✅ Kaise use karu

Har folder ke andar ek `resources.md` file hai. Naya link add karna ho to:

1. Sahi folder me jao (agar naya topic hai to naya folder bana lo)
2. `resources.md` open karo
3. Neeche diye format me entry add karo

```markdown
- [Resource Title](https://link.com) — 1 line note ki ye kis liye hai / status (✅ done / ⏳ pending)
```

## 🏷️ Status Legend

- ⏳ Pending — abhi padhna/dekhna hai
- 🔄 In Progress — chal raha hai
- ✅ Done — complete ho gaya

## 💡 Tip

GitHub ke top search bar se `path:learning-resources` likh kar kisi bhi keyword se apna saved resource turant dhund sakte ho.
